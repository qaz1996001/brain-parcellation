## 🎯 文檔風格和標準

### Pandas DataFrame 標準應用

所有文檔遵循 NumPy/Pandas 風格：

```python
def/class Element:
    """
    單行簡潔總結。
    
    多行詳細說明，包括背景、用途、設計考量等。
    可以多段落，但避免過度冗長。
    
    Parameters (或 Attributes)
    ----------
    name : Type
        參數說明。可以多行。
    
    Returns (或 Methods)
    -------
    Type
        返回值說明。
    
    Raises
    ------
    ExceptionType
        拋出異常的情況。
    
    Examples
    --------
    >>> 代碼示例
    >>> 展示實際用法
    
    Notes
    -----
    設計特點、注意事項、最佳實踐等。
    
    See Also
    --------
    相關函數或類。
    """
```

### Good Taste 設計原則

每個組件都說明了如何應用設計原則：

**1. 消除特殊情況**
- 統一事件驅動流程 (無 if-elif 鏈)
- 使用列舉而非魔術字符串
- 複合主鍵消除 UUID 特殊處理

**2. 資料結構驅動**
- DCOPStatus 列舉統一狀態定義
- JSON 欄位而非固定模式
- 配置表而非硬編碼邏輯

**3. 鬆散耦合**
- 事件驅動而非直接 API 呼叫
- 檢查點推動而非自動轉遷
- 外部工具集成最小化

**4. 扁平化邏輯**
- Early return 原則
- 無 3 層以上嵌套
- 明確的錯誤處理
