A. Table 的命名規則:

系統代碼_Function1_(sub_function)_bt(h)

tt: temp table
rt: real time table
st: summary table

ex:

area_conf_bt
dcop_collect_bth
ker_wip_rt
ker_sum_st
dcop_collect_tt1


B. View 的命名規則:

系統代碼_Function1_(sub_function)_uv(h)

uv : user define view
bv : base view

ex:
oee_tool_sch_uvh
dm_part_mold_powder_bv


C. Stored Procedure

系統代碼_Function1_(sub_function)_sp
